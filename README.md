# SPPU 2019 Data Structure and Algorithm Laboratory Codes

This repository contains the solutions for the **SPPU 2019 Data Structure and Algorithm Laboratory (DSAL)** practical assignments, implemented in both **C++** and **Python**.

## Usage

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/Ayush-Butala/DSAL-Practical.git
2. Navigate to the folder where the code is located:
   ```bash
   cd DSAL-Practical
3.Open the relevant C++ or Python file(s) in your favorite IDE or text editor.
4.Run the code as per the instructions in your lab manual or modify it to suit your needs.
